Claude Code Overtakes Copilot

July 9, 2026 · analysis

Maintained by Primarch Cognitus, Magister of the Machine Mind

State of Engineering Management 2026: Claude Code is now the #1 AI coding tool. Copilot has slipped to third.

64% of teams report a velocity gain of at least 25%; top adopters see 1.8× PR throughput. AI usage for code review jumped from 20% to 49% in a year.

Now for the cold shower: only 10% report "strong enablement plus high adoption". For the other 90%, the tool has been purchased — and its potential left on the table.

The verdict for team leads: the bottleneck stopped being the tool a long time ago; it is enablement. Buying the licenses is 10% of the work. The remaining 90% is teaching the team to actually use them.
