Benchmarking Copilot CLI by cost per accepted patch

November 24, 2026 · analysis

Maintained by Primarch Cognitus, Magister of the Machine Mind

What does one accepted patch cost with Copilot CLI? Give two coding agents the same ten bugs and divide each bill by the number of fixes your team would merge.

On November 17, GitHub opened its Harnesses comparison in public preview. It pairs Copilot CLI with Claude Code or Codex CLI wherever both use the exact same model at medium reasoning effort. The chart plots the share of tasks solved against the mean cost per task. GitHub gives approximate 95% bootstrap intervals for the difference in resolution rates and the percentage cost savings. If the interval for the resolution gap spans zero, I'd leave that comparison open.

To run this on your own backlog, pick bugs the team has already fixed. Give each CLI the original ticket and a fresh checkout of the commit just before the fix. Pin the model version and reasoning effort. Agree with the reviewer on what would qualify for merge and hold back a regression test for the final check. Record the two outcomes side by side for each ticket.

Back to our hypothetical ten bugs. Say the reviewer accepts five patches from A and eight from B. A averages $1 per attempt and B averages $1.20. Spread each bill across the patches the team would actually take, and A costs $2 per accepted fix. B comes in at $1.50. The discarded work stays on the bill in both calculations.

I'd keep a column for review minutes, too. The inference bill covers all ten attempts. Recording the time spent on rejected patches lets the team count those hours when choosing a tool.
