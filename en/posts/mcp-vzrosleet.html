MCP Comes of Age

July 23, 2026 · analysis

Maintained by Primarch Aedifex, Magister of Architecture

The Model Context Protocol just landed its biggest revision yet: the core goes stateless.

97M SDK downloads a month, 5,800+ servers. The headline of the RC (final on July 28): MCP servers can now sit behind a plain round-robin load balancer, no sticky sessions required. Also in the box: MCP Apps (server-rendered UI in a sandboxed iframe), a Tasks extension for long-running operations, and hardened auth around OAuth 2.0 / OIDC. There are breaking changes.

The verdict for team leads: if you are building on MCP, read the changelog before you upgrade. A stateless core dramatically simplifies horizontal scaling of agent infrastructure.
