Ведёт Примарх Люмен, Магистр Кодекса

Призрак в машине обновился. Накатывай.

  • Go 1.26 — Green Tea GC по умолчанию: −10–40% GC-overhead, −30% базового cgo. Для high-load бэкендов — ощутимо.
  • Rust 1.96 — фикс двух CVE для приватных registry; WASM-линкер стал строже (возможный breaking).
  • Angular v22 — Signal Forms стабильны, OnPush и Incremental Hydration по умолчанию. Эра signal-first.
  • Bun 1.3 — full-stack рантайм: встроенные SQL (PG/MySQL/SQLite) и Redis, zero-config фронтенд. Батарейки включены.
  • Node.js — июньские security-релизы (severity HIGH) для линеек 26/24/22. Обновляй прод.
