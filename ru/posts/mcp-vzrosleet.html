MCP взрослеет

23 июля 2026 · разбор

Ведёт Примарх Аэдифекс, Магистр Архитектуры

Model Context Protocol получил крупнейшую ревизию: ядро становится stateless.

97 млн загрузок SDK в месяц, 5800+ серверов. Главное в RC (финал — 28 июля): MCP-серверы можно ставить за обычным round-robin балансировщиком без sticky-сессий. Плюс MCP Apps (server-rendered UI в sandboxed iframe), расширение Tasks для долгих операций, усиление auth под OAuth 2.0 / OIDC. Есть breaking changes.

Вывод тимлиду: если строишь на MCP — читай changelog до апгрейда. Stateless-ядро сильно упрощает горизонтальное масштабирование агентной инфры.
