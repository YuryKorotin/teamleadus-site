  • October 13, 2026

    SlugFest: npm Trusted Publishing flaw hit 1,500+ packages

    Bloom Security disclosed SlugFest: npm's Trusted Publishing bound publish trust to a human-readable GitHub repository name instead of its immutable ID — rename or delete the repo, and anyone could claim the freed slug and ship new versions of someone else's package, complete with a valid Sigstore attestation. Over 1,500 packages with 10M+ downloads were exposed; the fix landed 120+ days after the report. AI agents installing dependencies with no human in the loop amplify the blast radius. Full analysis →
