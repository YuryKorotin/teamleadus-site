    wfx-loot: hijacked GitHub accounts stealing CI secrets

    Since November 10, the wfx-loot campaign has used 4,837 hijacked GitHub accounts to open over 66,200 pull requests titled "docs: dependency audit notes." The payload is a secret stealer: it runs in GitHub Actions and via npm install hooks, harvesting GitHub tokens, cloud credentials, package-registry publish tokens, and AI-provider API keys, then covers its tracks — reverting the commit and deleting run logs, in one case within 12 seconds. At least 1,806 repositories executed the payload; roughly 89% of probe PRs remain open.   • November 9, 2026

    AWS Nitro Sandboxes: a micro-VM per EKS pod, built in

    On November 9 AWS introduced Nitro Sandboxes: every EKS pod can run in its own lightweight virtual machine under the Nitro Hypervisor — with its own Linux kernel and the same hardware isolation boundary that separates EC2 instances. Enabling it takes one line in the pod spec (runtimeClassName); no separate sandbox service is needed — sandboxes live on the cluster's existing nodes; Kubernetes 1.36+ required. Confidential mode treats even the cluster administrator as untrusted and provides cryptographic attestation via KMS. The headline use case is code written and executed by AI agents: hardware isolation becomes a line in a manifest rather than separate infrastructure. Full analysis →

    EU AI Act deadline Dec 2 — synthetic content labeling

    December 2, 2026 is the EU AI Act deadline under Article 50(2) for systems placed on the market before August 2, 2026: synthetic content (text, images, audio, video) must be labeled and machine-detectable. The European AI Board has already shifted from writing rules to supervision — coordinating national authorities and setting enforcement priorities.
